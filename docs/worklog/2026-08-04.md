## NFC 祈福功能

- 在“更多”页面新增“祈福”入口。
- 新增 NFC 写卡页面，用户可以填写昵称和祝福语。
- 写卡前先把昵称、祝福语、账户 ID 和 APP 包名登记到云端，由服务端返回标准 UUID。
- NFC NDEF 中只保存 UUID，并附带 Android Application Record 用于把扫描事件路由到当前 APP。
- 新 NDEF 载荷估算约 `114 bytes`，可以适配常见约 144-byte 可用容量的 NTAG213。
- 保留对旧版 JSON NFC 贴纸的读取兼容。
- 前台扫描由 Reader Mode 处理；APP 在后台时由 `NDEF_DISCOVERED` 拉起祝福展示页面。
- 祝福展示页面会根据 UUID 从云端获取昵称和祝福语，包含卡片入场、光晕和触觉反馈效果。
- 云端获取失败时提供重试入口。
- 扫描事件支持本地待同步队列；登录和联网后自动同步。
- 自己扫描自己的祝福不会被过滤，并在对应代码处保留了日志和后续处理注释。
- 新增“我发起的”和“我收到的”祈福列表。

## Server 与数据模型

- 登录响应增加 `userId`，并新增 `GET /me`。
- 新增 `blessing_tags` 表，保存贴纸 UUID、发送账户、昵称、祝福语、APP 包名和创建时间。
- 新增 `blessing_events` 表，记录每次祈福扫描及接收账户。
- 新增接口：
  - `POST /blessings/tags`：登记祝福并生成 UUID。
  - `GET /blessings/tags/{uuid}`：通过 UUID 获取公开祝福详情。
  - `POST /blessings/receive`：幂等记录一次收到的祈福。
  - `GET /blessings`：获取当前账户发起和收到的祈福。
- 同一个扫描 `eventId` 重试不会产生重复事件。
- 自祈福事件在服务端正常保留，并返回 `isSelf=true`。
- 更新了 `server/API.md` 接口文档。
- 管理后台新增“祈福记录”页面，可分页查看全部发送/接收事件及双方账户、祝福内容、贴纸 UUID、APP 包名、接收时间和自祈福标记。
